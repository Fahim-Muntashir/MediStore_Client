# OnlineHat - Full-Stack Freelancing Marketplace

OnlineHat is a premium, feature-rich freelancing platform designed to connect talented service providers with clients worldwide. It features a robust architecture supporting role-based dashboards, tiered service offerings, and secure end-to-end order management.

## 🚀 Key Features

### 👤 Role-Based Dashboards
- **Buyer Dashboard**: Manage purchased orders, track project progress, and communicate with sellers.
- **Seller Dashboard**: Create and manage "Gigs," track earnings, manage active orders, and update delivery status.
- **Admin Panel**: Oversee the entire marketplace, manage users, monitor transactions, and handle dispute resolutions.

### 📦 Service Management (Gigs)
- **Tiered Pricing Models**: Create services with customizable **Basic**, **Standard**, and **Premium** packages.
- **Dynamic Offerings**: Define specific delivery times, revision counts, and feature inclusions for each tier.
- **Rich Media Support**: Add high-quality images and detailed descriptions to showcase services.

### 💳 Secure Payment Integration
- **Transaction Security**: Fully integrated with **Stripe** for secure credit card processing.
- **Escrow-like System**: Payments are held securely and released upon successful order completion.
- **Invoicing**: Automatic generation of invoices for every transaction.

### 🛠️ End-to-End Order Management
- **Workflow Tracking**: Full visibility from Order Placement → Technical Requirements → In Progress → Delivery → Revision → Completion.
- **File Delivery**: Integrated secure file upload system for project deliverables.
- **Revision Requests**: Clients can request modifications based on the service tier agreement.

### 💬 Communication & Community
- **Real-time Messaging**: Direct buyer-seller chat system for project discussions.
- **Review & Rating System**: Double-blind review system to maintain platform integrity and trust.
- **User Profiles**: Comprehensive profiles showcasing skills, portfolios, and past ratings.

## 💻 Tech Stack

- **Frontend**: Next.js (App Router), TypeScript, Tailwind CSS
- **Interactions**: Framer Motion, Lucide React Icons
- **Backend**: Node.js, Express.js
- **Database**: Postgress with Prisma
- **Authentication**: JWT (JSON Web Tokens) with Secure Cookies
- **Payments**: Stripe API
